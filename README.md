**Key Features**
- Trainer registration, login, and authentication.
- Complete student CRUD operations.
- Trainer-specific student record access.
- Duplicate student ID and email validation.
- Database operations using Django ORM.

**What I Learned:** Django authentication, ORM, database integration, validation, and access control.

### 2. Study Buddy – Collaborative Learning Platform

**Python | Django | MySQL | HTML | CSS**

A collaborative learning platform where students can create and join topic-based study rooms, exchange knowledge, and participate in discussions.

**Key Features**
- User registration, login, and logout.
- Create, update, view, and delete study rooms.
- Search rooms by topic and room name.
- Join and leave study rooms.
- Member-based messaging and discussions.
- Room creator-based access control.
- MySQL integration using Django ORM.

**What I Learned:** Database relationships, authentication, search functionality, messaging, and authorization.

### 3. In-Vehicle Audio Event Detection

**Python | WavLM | Machine Learning | Scikit-learn**

A machine learning-based system designed to detect vehicle audio events to enhance driver alertness and road safety.

**Key Features**
- Audio feature extraction using pretrained WavLM.
- Vehicle audio event classification.
- Implementation of multiple machine learning classifiers.
- Proposed Greedy Forest Classifier.
- Model evaluation using accuracy, precision, recall, and F1-score.

**What I Learned:** Audio processing, transformer-based feature extraction, machine learning, and model evaluation.
